# L38 Company Landing Page

Static corporate landing page for GitHub Pages.

## Structure

- `index.html` - page markup
- `assets/css/styles.css` - layout, responsive design and animation
- `assets/js/main.js` - language switcher, smooth scroll, menu and reveal effects
- `assets/lang/*.json` - Vietnamese, English, Chinese, Japanese and Korean content
- `assets/images` - logo, office images and Zalo QR images

## GitHub Pages

Upload this folder to a GitHub repository and enable GitHub Pages from the repository settings. The site uses relative paths, so it can run from the repository root or a GitHub Pages project path.

## Local Preview

Run a small local server from this folder:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```
